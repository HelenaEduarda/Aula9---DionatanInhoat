Aprendendo CSS Grid

Organizando elementos em linhas e colunas

O que é Grid?

CSS Grid é o que permite organizar elementos em linhas e colunas. Assim, fica mais easy montar layouts para uma página.

Principais propriedades

display: grid;

Ativa o Grid no elemento que contém os itens.

grid-template-columns

Define a quantidade e o tamanho das colunas.

grid-template-rows

Define o tamanho das linhas.

gap

Define o espaço entre as linhas e as colunas.

Exemplo prático

No exemplo, temos três colunas e seis itens. Os que não cabem na primeira linha passam para a próxima.

Onde posso usar?

Grid pode ser usado para organizar cartões, galerias de imagens e várias áreas de um site.
