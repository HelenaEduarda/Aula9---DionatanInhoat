Aprendendo Flexbox

Organizando elementos com CSS

O que é Flexbox?

Flexbox é uma ferramenta do CSS que ajuda a organizar os elementos da página em linhas ou colunas. Ele também facilita o alinhamento das coisas.

Principais propriedades

display: flex;

Ativa o Flexbox no elemento que contém os outros itens.

flex-direction

Define a direção dos itens. Pode ser row (linha) ou column (coluna).

justify-content

Organiza os itens no eixo principal, como no início, no centro ou com espaços entre eles.

align-items

Alinha os itens no eixo perpendicular ao principal.

Exemplo prático

Onde podemos usar?

Você pode usar Flexbox em menus, botões e cartões, por exemplo, quando você quiser alinhar os elementos de maneira simples.
